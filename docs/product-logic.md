# Product logic

## Смысл

Сайт не пытается доказать, что у конкретного застройщика есть системная проблема. Он показывает публичные сигналы, где есть конкретика: объект, застройщик, стадия, дефект, число замечаний, замер или гарантийный/судебный хвост.

Главный вопрос не в том, насколько громкий пост. Главный вопрос: что за процесс виден за дефектом.

## Отбор карточек

Карточка получает больше веса, если есть:

- ЖК;
- застройщик;
- число замечаний;
- конкретные детали дефекта;
- несколько категорий;
- стадия гарантия / суд / выдача ключей.

Каналы рыночного обогащения показываются отдельно по типу источника и не смешиваются с прямыми приемочными сигналами.

## Тон

Разрешено:

- публичный сигнал;
- наблюдение из открытого источника;
- конкретика по посту;
- не рейтинг застройщиков;
- каждая карточка ведет к первоисточнику.

Нельзя:

- компромат;
- проблемный застройщик;
- системная проблема как утверждение;
- вопросы для звонка;
- прямой sales-питч в карточке.
